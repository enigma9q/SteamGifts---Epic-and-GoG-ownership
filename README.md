# SteamGifts — Epic & GOG Ownership

A Tampermonkey userscript that keeps track of games owned on Epic Games Store and GOG and marks matching SteamGifts giveaways.

## Features

- Epic ownership synchronization from the Epic account purchases page.
- GOG ownership synchronization from the GOG account library.
- EPIC and GOG ownership markers on SteamGifts giveaways.
- Store synchronization buttons integrated directly into the relevant store pages.
- Epic button beside **Purchases**.
- GOG button beside **My Collection**.
- Small synchronization popups with visible status, owned-title count, last-sync time, and a bottom-right close button.
- SteamGifts ownership panel with direct links to the relevant Epic and GOG synchronization pages.
- Manual marker refresh.
- Local Tampermonkey storage for the synchronized libraries.

## Installation

Install the `.user.js` file in Tampermonkey and enable the script.
